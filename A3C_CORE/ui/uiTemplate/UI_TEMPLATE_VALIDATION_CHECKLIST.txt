FAILURE PATTERNS (QUICK DEBUG)

Buttons do nothing
→ handler not wired OR wrong function name

UI opens but empty
→ cacheControls failed OR wrong IDC

Undefined variable error
→ function not registered through XEH_PREP.hpp or initFunctions.sqf not compiled

UI flickers but no change
→ handler runs but does not call logic

Macro / bracket error
→ missing #include "script_component.hpp" or bad macro expansion

Config event string wrong
→ used QUOTE(...) instead of EXPAND_AND_QUOTE(...)
